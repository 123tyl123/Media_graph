# FRAME · 媒体图谱工作台

基于 React Flow 的本地媒体图谱：10,000 个图片 / 视频节点、二叉树初始结构、拖拽与缩放、手动连线、IndexedDB 增量保存、聚合总览。

开发协作从 [AGENTS.md](AGENTS.md) 开始；图、存储、媒体、性能和验证约定见 [PROJECT_RULES.md](PROJECT_RULES.md)。

## 启动

需要 Node.js 22.12+；本次使用 Node.js 22.22.3。

```powershell
cd C:\Users\tyl\Desktop\test
npm run dev
```

打开终端显示的地址，通常为 `http://127.0.0.1:5173/`。如果依赖已经安装，可直接执行最后一条命令。

```powershell
npm run dev
```

`build` 生成 `dist/` 和约 2 MB 的 `standalone.html`。单文件包含应用、六张示例图片和示例视频，不依赖外部 CDN；正式验收请使用 HTTP 服务，文件页面的访问和存储能力取决于浏览器策略。

开发服务运行时，也可打开 `/dist/index.html` 检查已编译的生产代码；生产包重新构建后需要刷新该页面。正式部署使用 `dist/` 的静态文件。

## 使用

- 默认生成 10,000 节点、9,999 条连线；可切换 100 / 1,000 / 10,000 三档数据。
- 拖拽卡片改变位置，拖动空白平移，滚轮或左下角按钮缩放。
- 输入数字或完整 ID 定位，例如 `9999` / `node-9999`；点击右侧父子关系也可定位。
- 点击媒体预览按钮。图片打开原图；视频只在预览时创建一个播放器，关闭即释放。
- 在右侧替换本地图片或视频。原文件以 Blob 存储，图片另生成小尺寸 WebP 缩略图；视频使用通用示例封面。
- 连线时先断开目标的父连线，再从父节点底部拖到目标顶部；也可在右侧输入目标 ID。每个节点最多一个父节点、两个子节点，禁止重复、自连和环。
- 选中边后可点击“断开”，或按 Delete / Backspace。节点删除被禁用，避免隐式删除子树。
- 总览以子树聚合卡片展示，点击进入真实节点。缩小超过阈值会进入总览。全部真实数据仍保留，并可按 ID 访问。
- 等待顶部显示“已保存到本地”后再关闭。保存失败会显示提示，可导出图数据并重试。

切换数据集会覆盖当前图，界面会要求确认。已导入媒体仍保留在当前工作区的素材库；原始节点的位置不会在拖拽时自动重新布局。

## 性能设计

1. 完整图在 Zustand 中保存，详情由 React Flow 做视口裁剪。固定节点宽高，稳定组件、事件回调和配置引用。
2. 低缩放简化卡片；全图模式构建独立的聚合投影，初始二叉树仅展示 31 个概览节点。投影不会覆盖真实节点和连线。
3. 图片按可见节点加载缩略图，Blob URL 缓存保留引用计数；空闲缓存超过 100 项时淘汰。大量同时可见的有效引用会保留至卸载。
4. 拖拽结束才写节点，连线修改和视口停止后保存变更。保存队列合并变更并串行写入；旧写入失败不会覆盖较新的值。
5. 切换数据集使用主键范围删除和批量写入，避免逐条游标删除。

“性能观察”显示图数据初始化时间、实时 FPS、挂载数量，提供视口裁剪开关，以及 3 秒自动平移采样和记录导出。空闲 FPS、自动平移 FPS 和实际拖拽性能是不同测量；报告中注明测试方法和素材规模。

## 检查

```powershell
npm.cmd test
node scripts/model-benchmark.mjs
npm.cmd run build
```

42 项自动检查覆盖生成计数、层级、连线约束、聚合计数、数据替换、保存恢复、并发队列、失败后重试、成功写入期间的新编辑，以及损坏记录隔离。IndexedDB 单元检查使用 fake-indexeddb，不能代替真实浏览器验收。

提交前可运行 `npm.cmd run check`，顺序执行单元测试与生产构建；GitHub Actions 使用相同命令。CI 配置已提供，远端运行结果以实际上传后的 Actions 记录为准。

本轮 AI 协作过程、关键决策和展示路径见 [docs/AI_WORKFLOW.md](docs/AI_WORKFLOW.md)。新增的同条件拖拽 / 平移对比见 [docs/performance/COMPARISON.md](docs/performance/COMPARISON.md)。

```powershell
npm.cmd run preview
# 另开一个终端
npm.cmd run test:e2e
```

受限 shell 内可能无法启动独立浏览器，且沙箱内服务可能无法被外部浏览器访问。本轮在授权后于沙箱外运行本机 preview 和 Edge。历史应用内浏览器验收与本轮结果分别记录于 `VALIDATION.md`。

## 数据与工作区

IndexedDB 数据库默认名 `frame-media-graph`，包含 graphs、nodes、edges、assets 四张表。

为验收隔离数据，可在地址后加 `?workspace=acceptance`。允许 1～48 位字母、数字、下划线、连字符，使用独立的本地数据库，不覆盖默认图谱。

恢复时会在同一只读事务中检查图版本、记录数量、节点字段、视口和二叉森林结构。恢复失败会保留原记录，显示可探索的临时示例并阻止图写回；此时素材导入不可用。明确确认重新生成数据集后恢复正常保存。临时示例的导出只包含当前内存示例，不是损坏原记录的备份。

导出 JSON 包含真实图结构、位置、视口和导入媒体的元数据，**不包含媒体二进制文件**。本版本提供导出，没有实现 JSON 导入、跨设备同步或完整媒体备份。浏览器清理站点数据后，本地记录可能丢失。

## 素材

- 六张 SVG 风景示例为本项目原创，由 `scripts/create-assets.mjs` 生成，可随本项目使用。
- 视频为 MDN Interactive Examples 的 CC0 Flower 示例，下载后随项目提供：
  `https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4`
- 10,000 个节点复用这些素材；本次不代表 10,000 个独立高清媒体文件的加载或解码能力。

## 当前边界

- 初始为等间距的分层二叉树布局，深层图较宽，可用定位和总览导航。重连保留当前位置，初始层级字段不会被当作实时拓扑层级。
- 极端情况下分离出超过 63 棵独立树，总览仅列出前 63 个根；所有真实节点仍可通过 ID 搜索访问。
- 当前按单个工作区单标签页编辑设计；不同工作区可独立使用，同一工作区多标签页没有冲突协调。
- 图片导入兼容 SVG 解码回退。视频导入不生成真实首帧封面，格式能否播放取决于浏览器编解码器。
- 尚未实现撤销、图谱导入、媒体库清理、完整重新布局、协作或后端。
- 构建有单个 JS chunk 超过 500 kB 的提示，压缩传输约 172 kB；此提示不阻止构建。
